# Terminal UI

flexLingua provides a local terminal application with exactly three modes: Translate, Chat, and Forms. It runs directly on Node.js and does not start an HTTP server or browser page.

## Start

Use Node.js 22.12.0 or newer and install the locked dependencies from the repository root:

```sh
npm ci
npm run tui
```

On Windows, `start.bat` starts the same application after dependencies have been installed. The application needs an interactive terminal. If it is started from a pipe or CI job, it exits with a message pointing to the standalone CLI.

## Navigation

- F1, F2, and F3 select Translate, Chat, and Forms. All controls are available from the keyboard; mouse navigation is not supported.
- Tab and Shift+Tab move focus. Enter activates the focused action or submits the current input. Esc closes an open panel or cancels a confirmation.
- Type `/settings` in the composer to edit session-only language and presentation settings. Apply commits the working copy; Cancel or Esc discards it. `/help` lists the current controls and commands.
- Ctrl+C exits and restores the terminal input mode and cursor.
- Ctrl+N opens the new-session confirmation in Chat. Confirming resets its in-memory dialogue session and history; cancelling preserves them.
- When the Chat conversation or Translate details are focused, `j` and `k` scroll down and up.

## Tabs

### Translate

Choose a declared source and target direction, enter a sentence, and press Enter on the source field or Translate action. Supported directions produce the Engine result and a MeaningGraph summary. Unsupported directions remain explicit and return diagnostics. Swap is available only when the reverse direction is declared. Use Details to inspect the complete meaning, alternatives, information loss, and diagnostics.

### Chat

Enter one utterance and press Enter. The conversation labels the user utterance, semantic reading, any Engine response, and diagnostics separately. The Engine only attempts a generated response after a successfully parsed `ask` act, and a response is shown only when the planner provides a supported realization. Unsupported input remains a diagnostic.

The session language, local status, and `turnCount/maxTurns` are shown above the scrollable conversation. The session and visible history exist only in process memory; they are not written to disk.

### Forms

Choose a language and search for a lemma or an inflected surface form. If the dictionary returns multiple entries, select one explicitly. The view shows only forms supplied by that language's morphology provider. Unknown forms are not generated by the UI.

## Terminal size

At fewer than 40 columns or 12 rows, the app asks you to enlarge the terminal. Resize events redraw the active mode while keeping its focus and selection.

## Standalone CLI

The CLI remains available without starting the TUI:

```sh
node tools/translate.mjs --languages
node tools/translate.mjs --from en --to pl --text "The girl sees the dog." --json
```

See [CLI usage](cli.md) for output fields, diagnostics, and exit codes. The redesign specification is tracked in [issue #324](https://github.com/clickbytes/flexLingua/issues/324).
