# Controlled information structure for transfer events

ADV-02 supports one bounded, explicit presentation choice: in a single `event.transfer_possession`, `agent` is the topic and either `theme` or `recipient` is the focus. `engine.realize` and `engine.translate` accept `informationStructure: {topic:'agent',focus:'theme'|'recipient'}`. The target plugin selects the earliest compatible legacy linearization. If none matches, it selects a compatible opt-in variant by ascending `realizationPreference`, then stable `variantId`. English and Polish have both legacy variants. Other event frames are rejected with `INFORMATION_STRUCTURE_UNSUPPORTED` until their alternatives are explicitly reviewed. This API describes a caller request, not a rule for deriving information structure from a sentence.

Recognizing a fronted constituent, including a Polish OVS sequence, does not call `createInformationStructure` or fill topic/focus. Surface order alone is insufficient evidence: the same ordering can serve different discourse purposes, and a bounded grammar need not analyze those purposes. When no explicit supported request or separately reviewed discourse evidence exists, presentation is unknown. An unsupported request remains a controlled refusal.

The semantic event is unchanged by the explicit presentation request. `eventSemanticSignature(event)` sorts one event document into a stable signature and omits its wire-version field; roles, participants, tense, aspect, polarity and other event fields remain part of the signature. Presentation options are held outside the event. The function is not a general logical-equivalence proof for states, questions, scopes or future MeaningGraph types. A different focus must not change participant roles or negation scope. A caller can serialize the event to CORE JSON and parse it back without storing a surface-order preference.

Approved sentence expectations belong in the canonical `tests/cases/**` matrix and require independent review. Their relational checks compare full MeaningGraph meaning while keeping surface evidence separate. The finite supported choice says nothing about general discourse topic detection, emphasis prosody or argument quality, and it is not CEFR certification. See the [ADR for bounded word-order variants](feature-driven-word-order.md).
